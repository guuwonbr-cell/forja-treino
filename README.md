# FORJA · Treino

Aplicativo web instalável (PWA) para acompanhar treinos e cardio. Versão inicial/MVP.

## Publicar com GitHub Pages
1. No repositório, abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
4. Aguarde a URL HTTPS ser publicada.

## Instalar no Android
Abra a URL no Chrome, abra o menu ⋮ e escolha **Instalar app** ou **Adicionar à tela inicial**.

## Dados e backup
Os dados são armazenados localmente neste navegador/aparelho. Use a aba **Dados** para exportar um JSON de backup e importar depois. Não há sincronização automática.

## Limitações desta versão
Esta é uma primeira versão funcional para testar. Ainda não contém a ficha pessoal pré-configurada, biblioteca de substituições, recomendações automáticas de progressão, nem sincronização ou IA. Valide tudo antes de depender dela para guardar seu histórico e mantenha backups.
